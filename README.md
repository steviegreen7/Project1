# Project1: AI-Driven Development Test

## Overview

Project1 is an experimental repository designed to evaluate the capabilities of AI agents in the end-to-end development of coded applications. This project serves as a sandbox for testing how effectively AI can architect, write, and refine code within a version-controlled environment.

## Features

* **AI-Generated Architecture**: Core logic and file structures designed through agent prompting.
* **Automated Coding Workflows**: Exploration of autonomous code generation and bug fixing.
* **Scalability Testing**: Evaluating how well the agent handles project growth from a simple script to a full application.

## Getting Started

### Prerequisites

* Git installed on your local machine.
* An active API key for your preferred LLM (if running agents locally).
* The runtime environment specific to the language used (e.g., Python 3.10+, Node.js, etc.).

### Installation

1. **Clone the repository:**
```bash
git clone https://github.com/steviegreen7/project1.git
cd project1

```


2. **Set up a virtual environment (if applicable):**
```bash
python -m venv venv
source venv/bin/activate  # On Windows use `venv\Scripts\activate`

```


3. **Install dependencies:**
```bash
pip install -r requirements.txt

```



## Usage

To begin a new AI-assisted coding session, initialize your agent pointing to the project root. You can use the existing codebase as context for the agent to suggest improvements or new features.

## Commitment & Contribution Rules

To maintain the integrity of the test, please follow these guidelines:

* **Branching Strategy**: All AI experiments should take place on a feature branch (e.g., `feature/ai-gen-logic`) before being merged into `main`.
* **Commit Messages**: Use clear, descriptive labels for commits.
* *Example*: `feat: add automated unit testing via AI agent`


* **Documentation**: Ensure any new logic added by an agent is accompanied by updated docstrings or comments.
